# V3 UI コンパクト CAD レイアウト

作成日: 2026-10-15
ステータス: **設計のみ。コード未変更。**
Phase 2A との関係: 案 C（右プロパティ常時表示）を**破棄**し、右 380px パネルを基本構成から外す。

本番公開はユーザーの明示承認があるまで禁止。

## 0. Phase 2A との相違

| 項目 | Phase 2A（案 C） | Phase 2B（本方針） |
|------|------------------|-------------------|
| 右ペイン | EAST 320px 常時（詳細・見積） | **なし**。詳細はコマンドポップアップ |
| 左ツール | アイコン + 一部常時セレクト可 | **アイコンのみ**。数値はポップアップ |

| 3D 面積 | 高 | **最大**（上下左右のクロムが細い） |

機能の廃止はしない。置き場だけ変える。

## 1. 基本レイアウト

```
┌─ NORTH 48px ──────────────────────────────────────────────────┐
│ ロゴ  ファイル名*  │ 開く 保存 保存As Undo Redo Reset │ 合計 ¥  │ 表示 ヘルプ │ ログイン │
├─ 48px ─┬──────────────────────────────────────────────┬ 任意 ─┤
│ WEST    │                 CENTER                      │        │
│ アイコン │              #view  3D                      │ 常時パネルなし │
│ グループ │         コマンドポップアップ（1つのみ）         │        │
│         │                                              │        │
│ STAFF*  │         接続チップ（STAFF時・極小）            │        │
└─────────┴──────────────────────────────────────────────┴────────┘
```

- `*` STAFF アイコンは認証後のみ WEST 下部に追加。
- 合計金額は NORTH 右寄りに常時。クリックでも見積ポップアップを開いてよい。
- 共同編集中のみ、CENTER 上端に 1 行チップ（オンライン人数・最終保存）。常時の大きなバーは置かない。

WEST 幅の目安: 48–56px。NORTH 高さの目安: 44–48px。

## 2. 領域と既存 DOM

| 領域 | 新UI | 既存の扱い（実装時） |
|------|------|----------------------|
| NORTH | 新規バー | `#page-title`, `#save-*`, `#undo-btn` 等をバーへ移すか、hidden のまま新アイコンが click() |
| WEST | 新規アイコン列 | `.cr-leftbar` は廃止せず生成先を WEST に。パーツトグル等は hidden `#panel` に残す |
| CENTER | `#view` 最大化 | `#panel` は `display:none` でも ID 維持。canvas resize 必須 |
| ポップアップ | `#v3-cmd-pop`（新規、実装時） | 中身は既存 input を **移動**するか、新 input が既存セレクトへ値を同期 |
| 見積合計 | NORTH の `#total` またはそのクローン | `#parts-table` は hidden 維持（`calcAndRenderEstimate` が書く） |
| STAFF | WEST 下部アイコン | `#admin-menu-overlay` はログインモーダルとして再利用可 |

## 3. アイコングループ（WEST、上から）

グループ間に区切り。縦に長くしすぎない（目安 12 個前後 + STAFF 4）。

1. **追加** — Joint, Beam, Pole, Leg
2. **編集** — 長さ, 材質, 接続, 削除
3. **板** — 棚板, 壁板
4. **配置** — 移動, 回転, 自動レイアウト
5. **表示** — 寸法, グリッド（トグル）, 色（カラーチャート）
6. **出力** — 見積, 図面, 背景/FIT（「その他」にまとめてもよい）
7. **STAFF**（認証後）— 共同編集, ToDo, 在庫, 価格

NORTH に置くもの（WEST に重複させない）: 開く, 保存, Undo, Redo, Reset, ヘルプ, ログイン。

詳細は `docs/V3_UI_ICON_COMMAND_MATRIX.md`。

## 4. コマンドポップアップの位置

初期案は **固定**（ドラッグなし）。

1. 原則: 押したアイコンの右隣（WEST のすぐ右、3D 上に浮かないか、少しかぶせる）
2. 上バーのアイコン: バーの直下
3. はみ出し: `getBoundingClientRect` ではみ出したら反転（右→左、下→上）
4. 同時に開くのは 1 つ。別アイコンを押すと前をキャンセル相当で閉じ、新しいのを開く（モードツールは例外: ポップアップを閉じてもモードは ON のまま）

仕様の詳細は `docs/V3_UI_POPUP_SPEC.md`。

## 5. 見積

| 要素 | 表示 |
|------|------|
| 合計 | NORTH に常時 `#total` 相当。設計変更のたびに既存 `requestEstimateRender` |
| 明細 | 見積アイコン → ポップアップ（テーブル + 見積へ送る + 製作数） |
| 価格マスタ変更 | STAFF の価格アイコン（別） |

hidden の `#parts-table` を更新し続け、ポップアップを開いたときに中身を見せる。計算ロジックは動かさない。

## 6. STAFF

- 未認証: WEST にログインアイコンのみ（または NORTH 右端）。在庫・価格・ToDo・共同編集アイコンは出さない。
- 認証後: 上記 4 アイコンを追加。接続中は CENTER 上にチップ（人数、保存未同期ならドット）。
- UI 非表示 ≠ 権限。書込は Firestore / 将来の Netlify Function で拒否する。
- 500ms 同期は現行 `staff-collab-mode.js` を**呼び出さない限り動かない**。新 UI は `openStaffCollaboration` を「共同編集アイコン確定後」だけ呼ぶ。自動開始しない。

---

## 7. 3D との関係

- 追加系モード ON 中は 3D クリックが本操作。ポップアップは長さ・オーダーの入力だけ。
- ポップアップ表示中も Orbit（中ドラッグ等）は維持。左クリックがフォーム上なら 3D に渡さない。
- Esc でポップアップを閉じる。モードツールは「モード OFF」か「ポップアップだけ閉じる」をツールごとに定義（マトリクス参照）。

---

## 8. 変更リスク（レイアウト）

- `#panel { width: 380px }` を外すと canvas が広がる。`resize` を 1 フレーム内で呼ぶ。
- hidden `#panel` が `display:none` だと一部の `offsetWidth` 依存が壊れる可能性 → 見積テーブルは vis-hidden でも DOM 接続を維持。
- `.cr-leftbar` と WEST の二重表示防止。
